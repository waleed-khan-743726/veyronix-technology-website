Engineering Case Study

Selected Engineering Work: Aervion.

COMPUTER VISION & APPLIED AI

Aervion — Smart Aerial Navigation System

An applied computer vision and drone flight control project built in Python and OpenCV with DJI Tello integration. Features real-time face detection, click-to-lock target identification, and autonomous following.

Key Engineering Problem: AI inference originally competed with the high-frequency flight-control loop. We improved the system by decoupling expensive vision processing from the flight stabilization loop using asynchronous non-blocking worker threads.
